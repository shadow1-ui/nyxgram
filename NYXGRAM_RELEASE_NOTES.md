## Nyxgram 0.3

- ID и DC фотографии в одной строке, копирование только ID.
- Меню username и ссылки по ID, локальные закладки профилей.
- Локальное сохранение удалённых сообщений и предыдущего текста правок, поиск и ограничение хранения.
- Настраиваемые значок и цвет удаления; код доступа и блокировка при сворачивании.
- Предпросмотр оформления до применения, четыре пресета, размер текста и скругление сообщений.
- Скрытие времени стикеров/GIF/видеосообщений, аватаров групп и разделителей дат.
- Экспорт/импорт безопасного набора настроек через выбор файла Android.
- Проверка стабильных GitHub Releases, контрольной суммы, пакета и подписи APK перед установкой.
- Экспериментальное отключение отправки просмотров историй без Premium.

Сохранение истории и её защита включаются отдельно. Секретные чаты, исчезающие сообщения и одноразовые медиа исключены. Архив не восстанавливает сообщения, которых устройство не получало. Медиа не копируются автоматически.

Экспериментальная невидимость историй не гарантирует анонимности, не отменяет старые просмотры и не скрывает реакции/ответы. Просмотр с другого клиента тоже может отправить отметку.

Первая установка версии с обновлятором выполняется вручную поверх существующего Nyxgram. Последующие опубликованные обновления доступны из приложения. Черновики и неудачные сборки не предлагаются.
